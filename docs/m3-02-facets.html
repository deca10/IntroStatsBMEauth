3.2 Facets, reference lines and annotations

Small multiples, more variables in one plot, and labels that tell the story

NoteIn this lesson you will learn to
  • split a plot into small multiples with facet_wrap() and facet_grid(),
  • show more variables with the aesthetics shape and size,
  • add reference lines (geom_hline(), geom_vline(), geom_abline()), and use an identity line to catch a data error,
  • annotate plots with text, and label individual athletes with ggrepel.

⏱️ About 40 minutes.

Small multiples with facet_wrap()

A facet splits one plot into several panels, one per group, all with the same axes. This is often clearer than squeezing every group into one panel with different colours. facet_wrap(~ variable) creates one panel per value of variable:

Useful arguments:

  • ncol / nrow: the layout of the panels,
  • scales = "free_y" (or "free_x", "free"): let each panel have its own axis range. Use this with care, because readers naturally compare panels as if the axes were the same!

Make histograms of body_mass_kg (binwidth = 5, fill = "steelblue", colour = "white"), with one panel per sport stacked vertically (ncol = 1), so the two distributions are easy to compare on the same x-axis.

facet_wrap(~ sport, ncol = 1). Don’t forget the tilde ~.

ggplot(squad, aes(x = body_mass_kg)) + geom_histogram(binwidth = 5, fill = "steelblue", colour = "white") + facet_wrap(~ sport, ncol = 1) 
ggplot(squad, aes(x = body_mass_kg)) +
  geom_histogram(binwidth = 5, fill = "steelblue", colour = "white") +
  facet_wrap(~ sport, ncol = 1)

Two-way grids with facet_grid()

facet_grid(rows ~ cols) makes a grid with one variable defining the rows and another the columns:

Use . for “no variable”: facet_grid(. ~ sex) gives one row of panels.

You use facet_wrap(~ sport, scales = "free_y"). What’s the risk?

Free scales are useful when groups have very different ranges, but the same visual height then means different values in different panels. Mention it in the caption, or keep the scales fixed when comparing groups is the point of the figure.

More variables: shape and size

Besides x, y, colour and fill, points have a shape (good for a categorical variable, especially in black-and-white print) and a size (for a numeric variable, a “bubble chart”):

This one plot shows four variables. Notice the pattern: for the same jump height (colour), athletes with a shorter push-off (x) produce a larger force (y). Keep this in mind for the regression lesson in Module 4!

Warning

Don’t overdo it. Four variables in one plot is usually the maximum readers can digest. If it gets crowded, use facets instead.

Reference lines

Reference lines give the reader a benchmark:

  • geom_hline(yintercept = ...): a horizontal line, e.g. a target value or a group mean,
  • geom_vline(xintercept = ...): a vertical line,
  • geom_abline(intercept = ..., slope = ...): any straight line. With intercept 0 and slope 1 it’s the identity line (y = x).

Catching a data error with an identity line

The dataset contains the peak (ecc_rfd_max) and the mean (ecc_rfd_mean) eccentric rate of force development of every athlete. By definition, the peak of a signal can never be smaller than its mean. Plot them against each other with the identity line y = x: every point must lie on the side of the line where max > mean.

Make a scatter plot of ecc_rfd_mean (x) against ecc_rfd_max (y) and add the identity line with geom_abline(intercept = 0, slope = 1, linetype = "dashed"). Then, on the last line of code, use subset() to find the athlete(s) whose max is smaller than their mean.

intercept = 0, slope = 1, and subset(squad, ecc_rfd_max < ecc_rfd_mean).

p <- ggplot(squad, aes(x = ecc_rfd_mean, y = ecc_rfd_max)) + geom_point() + geom_abline(intercept = 0, slope = 1, linetype = "dashed") print(p) # Which athlete(s) have max < mean? subset(squad, ecc_rfd_max < ecc_rfd_mean)[, c("id", "ecc_rfd_mean", "ecc_rfd_max")] 
p <- ggplot(squad, aes(x = ecc_rfd_mean, y = ecc_rfd_max)) +
  geom_point() +
  geom_abline(intercept = 0, slope = 1, linetype = "dashed")
print(p)

# Which athlete(s) have max < mean?
subset(squad, ecc_rfd_max < ecc_rfd_mean)[, c("id", "ecc_rfd_mean", "ecc_rfd_max")]

Annotations

Use annotate() to add text, arrows or shaded areas at specific coordinates. These are not mapped from the data:

Labelling individual points

To label points with a value from the data (e.g. athlete IDs), use geom_text() with the label aesthetic. When labels overlap, the ggrepel package’s geom_text_repel() pushes them apart. Labelling every point is cluttered, so pass a subset of the data to the label layer:

Each layer can use its own data via the data argument, which is very handy for highlighting.

Highlight and label the five athletes with the shortest contraction time (contraction_time_s) in a scatter plot of contraction_time_s (x) against jump_height_m (y).

  1. fast (the five fastest athletes) is created for you with order() and head().
  2. Add a red point layer and a geom_text_repel() layer that both use data = fast.

Use data = fast in both layers and aes(label = id).

fast <- head(squad[order(squad$contraction_time_s), ], 5) ggplot(squad, aes(x = contraction_time_s, y = jump_height_m)) + geom_point(colour = "grey50") + geom_point(data = fast, colour = "red", size = 3) + geom_text_repel(data = fast, aes(label = id), colour = "red") 
fast <- head(squad[order(squad$contraction_time_s), ], 5)

ggplot(squad, aes(x = contraction_time_s, y = jump_height_m)) +
  geom_point(colour = "grey50") +
  geom_point(data = fast, colour = "red", size = 3) +
  geom_text_repel(data = fast, aes(label = id), colour = "red")

Which function draws the line y = x?

geom_abline() draws a line with a given intercept and slope. Intercept 0 and slope 1 is the identity line, ideal for comparing two measurements of the same quantity (e.g. two devices, or test vs. retest).

In geom_point(data = top, colour = "red"), what does data = top do?

Every layer can have its own data. This is how you highlight or label a subset of observations.

Lesson summary

  • facet_wrap(~ var) → panels per group; facet_grid(rows ~ cols) → a grid; scales = "free" with care.
  • shape (categorical) and size (numeric) add variables, but don’t overload a plot.
  • Reference lines: geom_hline(), geom_vline(), geom_abline(); an identity line is great for spotting impossible values.
  • annotate() adds fixed text and shapes; geom_text_repel(data = subset, aes(label = ...)) labels selected points.
