4.9 Categorical data: chi-square tests

Testing proportions and associations between categorical variables

NoteIn this lesson you will learn to
  • test whether observed category counts match expected proportions (goodness-of-fit),
  • test whether two categorical variables are associated (chi-square test of independence),
  • calculate and use expected counts, and know when to use Fisher’s exact test instead,
  • report proportions and an effect size (Cramér’s V).

⏱️ About 35 minutes.

When the outcome is a category

t-tests, ANOVA and regression need a numeric outcome. When both variables are categorical (faller yes/no, injured yes/no, sex, playing position…), you analyse counts in a contingency table instead:

prop.table(tab, margin = 1) divides each row by its total: 25 % of older and 26 % of younger participants reported a fall.

Goodness-of-fit: does the sample match expected proportions?

Were men and women recruited equally? H₀: the population proportions are 50 % / 50 %.

The test compares observed counts O (116 F, 47 M) with expected counts E under H₀. With n observations and hypothesised proportions \(p_j\), \(E_j = n \times p_j\), here 163 × 0.5 = 81.5 each:

\[\chi^2 = \sum \frac{(\text{observed} - \text{expected})^2}{\text{expected}}\]

with df = (number of categories) − 1. χ² = 29.2, p < 0.001: women are clearly over-represented in this sample. That’s worth knowing before generalising any result to men!

Test of independence

Is falling associated with age group? H₀: the two variables are independent (the proportion of fallers is the same in both age groups).

Under H₀, the expected count in each cell is

\[E = \frac{\text{row total} \times \text{column total}}{\text{grand total}}\]

and the χ² statistic sums the squared differences between observed and expected counts over all cells, as above. For a table with r rows and c columns:

\[\chi^2 = \sum_{\text{all cells}} \frac{(O - E)^2}{E}, \qquad df = (r - 1)(c - 1)\]

Test whether falling (faller) is associated with age_group.

  1. Make the contingency table tab with table().
  2. Run chisq.test() on it and store the result in res.
  3. Look at the expected counts with res$expected.

table(balance$age_group, balance$faller) and chisq.test(tab).

tab <- table(balance$age_group, balance$faller) res <- chisq.test(tab) res res$expected 
tab <- table(balance$age_group, balance$faller)
res <- chisq.test(tab)
res
res$expected
NoteYates’ continuity correction

For 2 × 2 tables, R applies Yates’ correction by default (it says so in the output), which makes the test slightly more conservative by shrinking each |O − E| by 0.5:

\[\chi^2_{Yates} = \sum \frac{(|O - E| - 0.5)^2}{E}\]

With larger tables, no correction is applied.

A significant association, and its size

In the squad, are body-mass groups associated with sport?

χ²(2) = 44.9, p < 0.001: a very strong association (we already know basketball players are heavier).

With large samples, even weak associations become significant. Cramér’s V measures the strength of the association on a 0–1 scale:

\[V = \sqrt{\frac{\chi^2}{n \times (k - 1)}}\]

where n is the total count and k the smaller of the number of rows and columns. Rough benchmarks for k = 2: 0.1 small, 0.3 medium, 0.5 large.

Calculate Cramér’s V for the association between mass_group and sport. The χ² value is in res$statistic.

V <- sqrt(res$statistic / (n * (k - 1)))

tab2 <- table(squad$mass_group, squad$sport) res <- chisq.test(tab2) n <- sum(tab2) k <- min(nrow(tab2), ncol(tab2)) V <- sqrt(res$statistic / (n * (k - 1))) unname(V) 
tab2 <- table(squad$mass_group, squad$sport)
res <- chisq.test(tab2)

n <- sum(tab2)
k <- min(nrow(tab2), ncol(tab2))
V <- sqrt(res$statistic / (n * (k - 1)))
unname(V)

Small expected counts: Fisher’s exact test

The χ² test is an approximation that works well when all expected counts are at least 5. R warns you when they aren’t. Then use Fisher’s exact test, which calculates the p-value exactly. For a 2 × 2 table with cells a, b (first row) and c, d (second row) and total n, the probability of exactly this table, given the row and column totals, follows the hypergeometric distribution:

\[P = \frac{(a+b)!\,(c+d)!\,(a+c)!\,(b+d)!}{a!\; b!\; c!\; d!\; n!}\]

The p-value is the sum of the probabilities of all tables with the same totals that are as extreme as, or more extreme than, the observed one.

For 2 × 2 tables, fisher.test() also gives an odds ratio with its 95 % CI: the odds of being a faller in one group divided by the odds in the other:

\[OR = \frac{a / b}{c / d} = \frac{a\,d}{b\,c}\]

OR = 1 means no association. (fisher.test() reports a slightly different “conditional maximum-likelihood” estimate, which is usually close to this simple one.)

Which situation calls for Fisher’s exact test instead of a χ² test?

With small expected counts (< 5), the χ² approximation is unreliable. Means are compared with a t-test, not with a test for counts.

chisq.test(table(balance$fear_falling, balance$faller)) gives p = 0.58. The correct conclusion is:

A non-significant result means the data are compatible with independence; it doesn’t prove independence, and the test says nothing about direction.

Why shouldn’t you run a χ² test on a table of percentages?

χ² depends on the actual numbers: 10 % of 20 athletes and 10 % of 2000 athletes are very different amounts of evidence. Always use the raw counts.

Lesson summary

  • Count data → contingency table: table(a, b); proportions with prop.table(tab, margin = 1).
  • Goodness-of-fit: chisq.test(table(x), p = c(...)).
  • Independence: chisq.test(table(a, b)); inspect $expected.
  • Expected counts < 5 → fisher.test() (gives an odds ratio for 2 × 2 tables).
  • Effect size: Cramér’s V = √(χ² / (n·(k − 1))).
  • Plot with geom_bar(position = "fill").
