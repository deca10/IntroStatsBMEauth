1.2 Vectors

Storing, naming, calculating with and selecting a week of training data

NoteIn this lesson you will learn to
  • create vectors with c() and give their elements names,
  • do calculations with whole vectors at once (+, sum(), mean()),
  • select elements by position, by name and by comparison.

⏱️ About 40 minutes.

The story for this lesson

You are coaching a triathlete. Every weekday they run and cycle, and you record the distances (in km). By the end of the lesson you’ll be able to answer questions such as “How much did they train in total?”, “On which days did they run more than 10 km?” and “What was their average cycling distance early in the week?”

Create a vector

A vector is a sequence of values of the same type. You create one with the combine function c(), separating the values with commas:

Most data you collect is naturally a vector: the jump heights of a team, the heart rate every second, the names of all participants.

The triathlete’s distances from Monday to Friday are:

  • running: 8, 12, 5, 15, 10 km
  • cycling: 20, 0, 35, 15, 25 km

Create the vector running_km (given) and the vector cycling_km in the same order.

Use the same pattern as running_km: c(20, 0, 35, 15, 25).

# Running distances, Monday to Friday running_km <- c(8, 12, 5, 15, 10) # Cycling distances, Monday to Friday cycling_km <- c(20, 0, 35, 15, 25) 
# Running distances, Monday to Friday
running_km <- c(8, 12, 5, 15, 10)

# Cycling distances, Monday to Friday
cycling_km <- c(20, 0, 35, 15, 25)

What happens if you combine different types, e.g. c(12, "rest", 8)?

A vector can only hold one type. R converts all values to the most flexible type, here character: "12" "rest" "8". Try class(c(12, "rest", 8)) in a code box!

Naming a vector

Looking at running_km, it isn’t obvious which value belongs to which day. You can give each element a name with the names() function:

If you need the same names for several vectors, store them in a vector first and reuse it. That saves typing and avoids typos:

days_vector <- c("Monday", "Tuesday", "Wednesday", "Thursday", "Friday")
names(running_km) <- days_vector

The vector days_vector is created for you. Use it to name both running_km and cycling_km.

Put days_vector on the right-hand side of both assignments.

running_km <- c(8, 12, 5, 15, 10) cycling_km <- c(20, 0, 35, 15, 25) days_vector <- c("Monday", "Tuesday", "Wednesday", "Thursday", "Friday") # Assign the names of the days to running_km and cycling_km names(running_km) <- days_vector names(cycling_km) <- days_vector 
running_km <- c(8, 12, 5, 15, 10)
cycling_km <- c(20, 0, 35, 15, 25)
days_vector <- c("Monday", "Tuesday", "Wednesday", "Thursday", "Friday")

# Assign the names of the days to running_km and cycling_km
names(running_km) <- days_vector
names(cycling_km) <- days_vector

Calculating total training volume (example 1)

Arithmetic on vectors works element by element. If you add two vectors of the same length, R adds the first elements together, then the second elements, and so on:

This is extremely handy: with one line you can calculate a value for every day, every athlete or every trial.

Calculate the total distance per day (running + cycling) and store it in total_daily. Then print it.

Add the two vectors: running_km + cycling_km.

days_vector <- c("Monday", "Tuesday", "Wednesday", "Thursday", "Friday") running_km <- c(8, 12, 5, 15, 10) cycling_km <- c(20, 0, 35, 15, 25) names(running_km) <- days_vector names(cycling_km) <- days_vector # Total distance per day total_daily <- running_km + cycling_km # Print total_daily total_daily 
days_vector <- c("Monday", "Tuesday", "Wednesday", "Thursday", "Friday")
running_km <- c(8, 12, 5, 15, 10)
cycling_km <- c(20, 0, 35, 15, 25)
names(running_km) <- days_vector
names(cycling_km) <- days_vector

# Total distance per day
total_daily <- running_km + cycling_km

# Print total_daily
total_daily

Calculating total training volume (example 2)

Now let’s summarise the whole week. The function sum() adds up all elements of a vector, and mean() gives the average:

You can also compare values with >, < and ==. The result is a logical value:

  1. Calculate the weekly running total and store it in total_running.
  2. Calculate the weekly cycling total and store it in total_cycling.
  3. On the last line, check whether the triathlete cycled more than they ran (total_cycling > total_running).

Use sum(running_km) and sum(cycling_km), then compare them with >.

running_km <- c(8, 12, 5, 15, 10) cycling_km <- c(20, 0, 35, 15, 25) # Weekly totals total_running <- sum(running_km) total_cycling <- sum(cycling_km) # Did they cycle more than they ran? total_cycling > total_running 
running_km <- c(8, 12, 5, 15, 10)
cycling_km <- c(20, 0, 35, 15, 25)

# Weekly totals
total_running <- sum(running_km)
total_cycling <- sum(cycling_km)

# Did they cycle more than they ran?
total_cycling > total_running

What does c(2, 4, 6) * 2 return?

Arithmetic is applied to each element: 2×2, 4×2 and 6×2. This is called vectorisation, and it’s one of R’s superpowers.

Vector selection (indexing)

Often you only need part of a vector. You select elements with square brackets [ ]. Inside the brackets you put the position(s) you want. In R, the first element has position 1.

Tip

The shorthand c(Monday = 8, Tuesday = 12, ...) creates a vector and names it in one step.

  1. Select the cycling distance on Wednesday and store it in cycling_wednesday.
  2. Select the cycling distances from Tuesday to Thursday (use :) and store them in cycling_midweek.
  3. Select Monday and Friday by name and store them in cycling_edges.

Wednesday is the 3rd element. Tuesday to Thursday is 2:4. For names, use c("Monday", "Friday").

cycling_km <- c(Monday = 20, Tuesday = 0, Wednesday = 35, Thursday = 15, Friday = 25) # Wednesday (by position) cycling_wednesday <- cycling_km[3] # Tuesday to Thursday (use :) cycling_midweek <- cycling_km[2:4] # Monday and Friday (by name) cycling_edges <- cycling_km[c("Monday", "Friday")] 
cycling_km <- c(Monday = 20, Tuesday = 0, Wednesday = 35, Thursday = 15, Friday = 25)

# Wednesday (by position)
cycling_wednesday <- cycling_km[3]

# Tuesday to Thursday (use :)
cycling_midweek <- cycling_km[2:4]

# Monday and Friday (by name)
cycling_edges <- cycling_km[c("Monday", "Friday")]

hr <- c(62, 65, 61, 70). What does hr[-2] return?

A negative index removes that position, so you get everything except the second element.

Selection by comparison: step 1

Comparison operators let you ask questions about every element of a vector at once:

Operator Meaning
< / > less than / greater than
<= / >= less than or equal / greater than or equal
== equal to (two = signs!)
!= not equal to

The result is a logical vector: TRUE for the days with more than 9 km of running, FALSE for the others.

Create a logical vector long_ride that is TRUE for every day on which the triathlete cycled 20 km or more. Print it.

“20 km or more” means greater than or equal to: cycling_km >= 20.

cycling_km <- c(Monday = 20, Tuesday = 0, Wednesday = 35, Thursday = 15, Friday = 25) # Which days had 20 km or more of cycling? long_ride <- cycling_km >= 20 # Print long_ride long_ride 
cycling_km <- c(Monday = 20, Tuesday = 0, Wednesday = 35, Thursday = 15, Friday = 25)

# Which days had 20 km or more of cycling?
long_ride <- cycling_km >= 20

# Print long_ride
long_ride

Selection by comparison: step 2

Here is the trick: you can put a logical vector inside the square brackets. R then keeps only the elements where the logical vector is TRUE:

You can also do it in one step: running_km[running_km > 9].

Use long_ride to select only the cycling distances of the long-ride days. Store the result in long_ride_km.

Put the logical vector inside the square brackets: cycling_km[long_ride].

cycling_km <- c(Monday = 20, Tuesday = 0, Wednesday = 35, Thursday = 15, Friday = 25) long_ride <- cycling_km >= 20 # Select the distances of the long-ride days long_ride_km <- cycling_km[long_ride] long_ride_km 
cycling_km <- c(Monday = 20, Tuesday = 0, Wednesday = 35, Thursday = 15, Friday = 25)
long_ride <- cycling_km >= 20

# Select the distances of the long-ride days
long_ride_km <- cycling_km[long_ride]

long_ride_km

Advanced selection

You can combine selection with functions like mean() and sum() to answer more specific questions.

You can also combine conditions: & means and (both must be true), | means or (at least one must be true):

  1. Calculate the average cycling distance from Monday to Wednesday, selecting the days by name. Store it in early_week_avg.
  2. Count on how many days the triathlete did no cycling at all (== 0). Store it in rest_days.

Select with c("Monday", "Tuesday", "Wednesday"). For the rest days, cycling_km == 0 gives a logical vector, and sum() counts the TRUEs.

cycling_km <- c(Monday = 20, Tuesday = 0, Wednesday = 35, Thursday = 15, Friday = 25) # Average cycling distance Monday to Wednesday early_week_avg <- mean(cycling_km[c("Monday", "Tuesday", "Wednesday")]) # Number of days without cycling rest_days <- sum(cycling_km == 0) early_week_avg rest_days 
cycling_km <- c(Monday = 20, Tuesday = 0, Wednesday = 35, Thursday = 15, Friday = 25)

# Average cycling distance Monday to Wednesday
early_week_avg <- mean(cycling_km[c("Monday", "Tuesday", "Wednesday")])

# Number of days without cycling
rest_days <- sum(cycling_km == 0)

early_week_avg
rest_days

rpe <- c(6, 8, 3, 9, 7). What does rpe[rpe >= 7] return?

rpe >= 7 produces FALSE TRUE FALSE TRUE TRUE. Putting it in square brackets keeps the values where it is TRUE: 8, 9 and 7. (which(rpe >= 7) would give the positions 2, 4, 5.)

Which code counts how many values of rpe are above 5 and below 9?

Both conditions must hold, so you need & (and). sum() counts the TRUE values. The third option returns the values themselves (6 8 7), not how many there are.

Lesson summary

  • Create vectors with c(). All elements must have the same type.
  • Name elements with names(x) <- ... or c(Monday = 8, ...).
  • Arithmetic is element-wise. sum() and mean() summarise a whole vector.
  • Select with [ ]: by position (x[3], x[2:4], x[-1]), by name (x["Monday"]) or with a logical vector (x[x > 9]).
  • Combine conditions with & (and) and | (or).
