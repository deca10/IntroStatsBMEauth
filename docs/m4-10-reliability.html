4.10 Reliability

Typical error, CV, Bland–Altman plots, ICC and the smallest worthwhile change

NoteIn this lesson you will learn to
  • distinguish systematic bias from random error in repeated measurements,
  • calculate the typical error (TE) and the coefficient of variation (CV),
  • draw a Bland–Altman plot with limits of agreement,
  • estimate the intraclass correlation coefficient (ICC),
  • calculate the smallest worthwhile change (SWC) and judge whether a test can detect it,
  • find processing errors that inflate measurement error.

⏱️ About 50 minutes.

Why reliability matters

A coach tests an athlete’s CMJ before and after a training block: 38.0 cm → 40.5 cm. Did the athlete improve? That depends on how much the result would vary anyway if nothing had changed. That’s the test’s reliability. A test with a lot of noise can’t detect small but real changes.

The trials dataset contains three CMJs of 56 professional basketball and soccer players, performed one after another in a single session. Jump height and body mass were calculated by the force-platform software for every trial:

Each athlete’s true ability didn’t change within those few minutes, so differences between trials are measurement error (biological variability + technical error).

Two components of error

  1. Systematic bias: a consistent shift between trials, e.g. athletes jump higher in trial 2 because of a warm-up or learning effect. It’s the mean of the differences.
  2. Random error: the unpredictable trial-to-trial scatter. It’s the SD of the differences.

With \(d_i = x_{2,i} - x_{1,i}\) the difference between the two trials of athlete i:

\[\text{bias} = \bar{d} = \frac{1}{n}\sum_{i=1}^{n} d_i \qquad\qquad s_d = \sqrt{\frac{\sum_{i=1}^{n} (d_i - \bar{d})^2}{n - 1}}\]

Typical error and CV

The typical error (TE) is the standard deviation of an individual’s repeated measurements: the “± noise” of a single test result. From two trials:

\[TE = \frac{SD(\text{trial}_2 - \text{trial}_1)}{\sqrt{2}}\]

(Dividing by √2 because a difference contains the error of two measurements.) Expressed as a percentage of the mean, it’s the coefficient of variation:

\[CV = \frac{TE}{\text{mean}} \times 100\%\]

For trials 1 and 2:

  1. Extract t1 and t2 (jump heights; trials is sorted by athlete, so they line up).
  2. Calculate the differences d, the systematic bias (mean of d), the typical error te and the cv (use the mean of all trial 1 and 2 values).

t2 uses trial == 2; d <- t2 - t1; bias <- mean(d); te <- sd(d) / sqrt(2).

t1 <- trials$jump_height_cm[trials$trial == 1] t2 <- trials$jump_height_cm[trials$trial == 2] d <- t2 - t1 bias <- mean(d) te <- sd(d) / sqrt(2) cv <- te / mean(c(t1, t2)) * 100 round(c(bias = bias, te = te, cv = cv), 2) 
t1 <- trials$jump_height_cm[trials$trial == 1]
t2 <- trials$jump_height_cm[trials$trial == 2]

d <- t2 - t1
bias <- mean(d)
te <- sd(d) / sqrt(2)
cv <- te / mean(c(t1, t2)) * 100

round(c(bias = bias, te = te, cv = cv), 2)

Bland–Altman plot

A Bland–Altman plot shows agreement between two measurements: for each athlete, the difference (y) is plotted against the mean of the two trials (x). Three horizontal lines summarise it:

  • the bias (mean difference),
  • the 95 % limits of agreement: about 95 % of differences should fall between them (if the differences are roughly normal): \[LoA = \bar{d} \pm 1.96\, s_d\]

It shows whether the error depends on the size of the measurement, and it makes outliers stand out.

Complete the Bland–Altman plot of trials 1 and 2: compute ba$mean and ba$diff, the limits loa_low and loa_high, and add the three horizontal lines.

diff = t2 - t1, sd(ba$diff) in both limits, and yintercept = c(loa_low, loa_high).

t1 <- trials$jump_height_cm[trials$trial == 1] t2 <- trials$jump_height_cm[trials$trial == 2] ba <- data.frame(athlete = unique(trials$athlete), mean = (t1 + t2) / 2, diff = t2 - t1) bias <- mean(ba$diff) loa_low <- bias - 1.96 * sd(ba$diff) loa_high <- bias + 1.96 * sd(ba$diff) ggplot(ba, aes(x = mean, y = diff)) + geom_point() + geom_hline(yintercept = bias) + geom_hline(yintercept = c(loa_low, loa_high), linetype = "dashed") + labs(x = "Mean of trials 1 and 2 (cm)", y = "Trial 2 - trial 1 (cm)") 
t1 <- trials$jump_height_cm[trials$trial == 1]
t2 <- trials$jump_height_cm[trials$trial == 2]
ba <- data.frame(athlete = unique(trials$athlete),

                 diff = t2 - t1)

Finding processing errors

The force-platform software estimates body mass from the quiet-standing phase of every trial. An athlete’s mass can’t change by several kg within a few minutes, so a large difference between trials means the quiet-standing phase was not quiet (the athlete moved, or stepped on late), like CMJ 2 of Athlete K in lesson 2.5. A wrong body weight corrupts the whole force analysis, including jump height.

Athlete A02’s first trial has a body mass 2.8 kg lower than the other two, and a jump height 21 cm higher. That’s a processing error, not a jump.

  1. Calculate the range of body mass (max − min) across each athlete’s three trials with tapply(), and store it in mass_range.
  2. Store the IDs of the athletes with a range above 2 kg in flagged.
  3. Recalculate the typical error of trials 1–2 without the flagged athletes (te_clean).
  1. function(x) max(x) - min(x) (or diff(range(x)))
  2. mass_range > 2
  3. sd(d_clean) / sqrt(2)
# 1. Body-mass range per athlete mass_range <- tapply(trials$body_mass_kg, trials$athlete, function(x) max(x) - min(x)) # 2. Flagged athletes flagged <- names(mass_range)[mass_range > 2] flagged # 3. Typical error without the flagged athletes clean <- subset(trials, !athlete %in% flagged) d_clean <- clean$jump_height_cm[clean$trial == 2] - clean$jump_height_cm[clean$trial == 1] te_clean <- sd(d_clean) / sqrt(2) te_clean

An athlete’s estimated body mass is 82.0, 81.8 and 76.4 kg in three consecutive jumps. What do you do with trial 3?

A 5-kg change in a minute is impossible. Because body weight is used to calculate acceleration, velocity and jump height, an error in it propagates to everything.

Relative reliability: the ICC

The TE describes absolute reliability (in cm). The intraclass correlation coefficient (ICC) describes relative reliability: how well the test keeps athletes in the same rank order across trials. It compares the variability between athletes with the error within athletes (0 = no reliability, 1 = perfect).

You can calculate it from an ANOVA with athlete and trial as factors. One common form, ICC(3,1) (consistency of single measurements), is:

\[ICC = \frac{MS_{athletes} - MS_{error}}{MS_{athletes} + (k - 1)\, MS_{error}}\]

where k is the number of trials.

Common benchmarks (Koo & Li, 2016): < 0.5 poor, 0.5–0.75 moderate, 0.75–0.9 good, > 0.9 excellent. Cleaning the data moves the ICC from “moderate” to “good”. (The irr and psych packages calculate all ICC forms with confidence intervals.)

WarningA high ICC can hide a large error

The ICC depends on how different the athletes are. In a very heterogeneous group (youth players and professionals together), the ICC can be excellent even if the TE is large. Always report the TE or CV as well.

The smallest worthwhile change

How big must a change be to matter? For team-sport athletes, a common approach defines the smallest worthwhile change (SWC) as 0.2 × the between-athlete SD, i.e. a “small” effect size (Hopkins):

\[SWC = 0.2 \times SD_{between}\]

and remember from the central limit theorem that averaging m trials reduces the typical error of an athlete’s score:

\[TE_{\text{mean of } m} = \frac{TE}{\sqrt{m}}\]

Compare the TE with the SWC:

  • TE < SWC: the test can detect the smallest worthwhile change in a single athlete (“good” sensitivity),
  • TE ≈ SWC: “OK”, averaging several trials helps,
  • TE > SWC: the test is too noisy to detect the SWC in individuals.

Using the cleaned data:

  1. Calculate the between-athlete SD of trial 1 jump heights and the swc.
  2. Calculate te_clean again (trials 1–2) and the ratio te_clean / swc.
  3. Calculate the typical error of the mean of 3 trials, te_mean3, using the CLT: TE / √3.

swc <- 0.2 * sd(c1), ratio <- te_clean / swc, te_mean3 <- te_clean / sqrt(3).

mass_range <- tapply(trials$body_mass_kg, trials$athlete, function(x) max(x) - min(x)) clean <- subset(trials, !athlete %in% names(mass_range)[mass_range > 2]) c1 <- clean$jump_height_cm[clean$trial == 1] c2 <- clean$jump_height_cm[clean$trial == 2] # 1. Smallest worthwhile change swc <- 0.2 * sd(c1) # 2. Typical error and ratio te_clean <- sd(c2 - c1) / sqrt(2) ratio <- te_clean / swc # 3. Typical error of the mean of 3 trials te_mean3 <- te_clean / sqrt(3) round(c(swc = swc, te = te_clean, ratio = ratio, te_mean3 = te_mean3), 2) 
mass_range <- tapply(trials$body_mass_kg, trials$athlete, function(x) max(x) - min(x))
clean <- subset(trials, !athlete %in% names(mass_range)[mass_range > 2])
c1 <- clean$jump_height_cm[clean$trial == 1]
c2 <- clean$jump_height_cm[clean$trial == 2]

# 1. Smallest worthwhile change
swc <- 0.2 * sd(c1)

# 2. Typical error and ratio
te_clean <- sd(c2 - c1) / sqrt(2)
ratio <- te_clean / swc

# 3. Typical error of the mean of 3 trials
te_mean3 <- te_clean / sqrt(3)

round(c(swc = swc, te = te_clean, ratio = ratio, te_mean3 = te_mean3), 2)

CMJ: TE = 1.5 cm, SWC = 1.0 cm. An athlete improves from 41.0 to 42.0 cm. What’s the best conclusion?

A 1 cm change is well within ±1.5 cm (one TE) of random variation. You’d need a larger change, or repeated tests, to be confident.

Why does averaging three trials reduce the typical error by a factor of √3?

Exactly the standard-error logic of lesson 2.4. It assumes the errors of the trials are independent.

Lesson summary

  • Bias = mean of the trial differences; TE = SD(differences) / √2; CV = TE / mean × 100.
  • Bland–Altman: difference vs. mean, with bias ± 1.96 SD limits of agreement.
  • ICC: relative reliability from an ANOVA; always report it together with the TE/CV.
  • SWC = 0.2 × between-athlete SD; a test is sensitive when TE ≤ SWC. Averaging n trials divides TE by √n.
  • Check data quality (e.g. body-mass consistency): a few processing errors can make a good test look bad.
