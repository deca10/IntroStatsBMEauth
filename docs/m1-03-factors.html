1.3 Factors

Categorical variables: sex, age group, test conditions and activity levels

NoteIn this lesson you will learn to
  • explain what a factor is and why categorical data needs one,
  • inspect and rename factor levels,
  • count categories with summary(),
  • create ordered factors and compare their values.

⏱️ About 30 minutes.

What’s a factor and why would you use it?

Many variables in sport science are categorical: they put each observation into one of a limited number of groups.

  • sex: F, M
  • playing position: goalkeeper, defender, midfielder, forward
  • test condition: eyes open / closed, firm surface / foam
  • age group: young, old

In R, categorical variables are stored as factors. A factor looks like a character vector, but R knows that the values are categories (called levels). That matters because statistical tests and plots treat categories differently from free text: they count them, compare groups, colour them and put them in a sensible order.

You create a factor with the function factor():

Notice the extra line Levels: F M in the output: R has found the two categories.

Eight balance trials were performed under these vision conditions. Convert vision_vector into a factor called factor_vision and print it.

Use factor(vision_vector), then write factor_vision on the last line.

vision_vector <- c("Open", "Closed", "Open", "Open", "Closed", "Closed", "Open", "Closed") # Convert vision_vector to a factor factor_vision <- factor(vision_vector) # Print out factor_vision factor_vision 
vision_vector <- c("Open", "Closed", "Open", "Open", "Closed", "Closed", "Open", "Closed")

# Convert vision_vector to a factor
factor_vision <- factor(vision_vector)

# Print out factor_vision
factor_vision

Which of these variables should be stored as a factor?

Footwear type is categorical: each trial belongs to one of a few groups. Jump height and heart rate are continuous measurements and should be numeric.

Factor levels

Data files often use short codes, like "F" and "M". The function levels() shows the categories of a factor, and you can also use it to rename them, which is useful for tables and plots:

WarningOrder matters!

When renaming, the new names are matched to the existing levels in order. Always check the current order with levels() first: here it is "F" "M" (alphabetical), so "Female" must come first.

You can also choose the order of the levels yourself when you create the factor, with the levels argument:

The vector group_vector codes participants as "Y" (young) or "O" (old).

  1. Convert it to a factor factor_group.
  2. Rename the levels to "Old" and "Young" (check the order!).

levels(factor(group_vector)) is "O" "Y" (alphabetical), so the new names must be c("Old", "Young").

group_vector <- c("Y", "O", "O", "Y", "Y", "O") # Convert group_vector to a factor factor_group <- factor(group_vector) # Rename the levels levels(factor_group) <- c("Old", "Young") factor_group 
group_vector <- c("Y", "O", "O", "Y", "Y", "O")

# Convert group_vector to a factor
factor_group <- factor(group_vector)

# Rename the levels
levels(factor_group) <- c("Old", "Young")

factor_group

Ordered factors

Sex, vision and surface are nominal variables: there is no natural order between the categories. Other categorical variables do have an order. These are called ordinal variables:

  • physical activity level: Low < Moderate < High
  • fear of falling: Low < Moderate < High
  • injury severity: minor < moderate < severe

For ordinal variables you create an ordered factor by adding ordered = TRUE and listing the levels from lowest to highest:

The levels are now printed with < signs between them, showing the order.

The physical-activity levels of six participants are given in activity_vector. Create an ordered factor activity_factor with the order Low < Moderate < High.

Use ordered = TRUE and levels = c("Low", "Moderate", "High").

activity_vector <- c("High", "Low", "Moderate", "Moderate", "High", "Low") # Create an ordered factor activity_factor <- factor(activity_vector, ordered = TRUE, levels = c("Low", "Moderate", "High")) activity_factor 
activity_vector <- c("High", "Low", "Moderate", "Moderate", "High", "Low")

# Create an ordered factor
activity_factor <- factor(activity_vector,
                          ordered = TRUE,
                          levels = c("Low", "Moderate", "High"))

activity_factor

Ordered factors (example)

Let’s apply this to the real data. The balance dataset (one row per participant) has a column activity with each participant’s activity level. By default R would order the levels alphabetically (High, Low, Moderate), which makes no sense in a table or plot:

Create an ordered factor fear_factor from the column balance$fear_falling (fear of falling), with the levels Low < Moderate < High. Then summarise it.

The first argument is balance$fear_falling. The levels are c("Low", "Moderate", "High").

# Ordered factor of fear of falling fear_factor <- factor(balance$fear_falling, ordered = TRUE, levels = c("Low", "Moderate", "High")) # Summarise fear_factor summary(fear_factor) 
# Ordered factor of fear of falling
fear_factor <- factor(balance$fear_falling,
                      ordered = TRUE,
                      levels = c("Low", "Moderate", "High"))

# Summarise fear_factor
summary(fear_factor)

Comparing ordered factors

Because an ordered factor knows the order of its levels, you can compare its elements with <, >, == and so on. This doesn’t work for unordered factors (try it and R will give a warning).

  1. Store the activity level of the first participant in participant1 and that of the third participant in participant3.
  2. On the last line, check whether participant 1 is more active than participant 3.

Select with square brackets: activity_factor[1] and activity_factor[3]. Then compare with participant1 > participant3.

activity_factor <- factor(c("High", "Low", "Moderate", "Moderate", "High", "Low"), ordered = TRUE, levels = c("Low", "Moderate", "High")) # Select participants 1 and 3 participant1 <- activity_factor[1] participant3 <- activity_factor[3] # Is participant 1 more active than participant 3? participant1 > participant3 
activity_factor <- factor(c("High", "Low", "Moderate", "Moderate", "High", "Low"),
                          ordered = TRUE, levels = c("Low", "Moderate", "High"))

# Select participants 1 and 3
participant1 <- activity_factor[1]
participant3 <- activity_factor[3]

# Is participant 1 more active than participant 3?
participant1 > participant3

You compare two elements of an unordered factor, e.g. factor_sex[1] > factor_sex[2]. What happens?

For nominal factors there is no order, so “greater than” has no meaning. R warns you and returns NA. Use ordered = TRUE when the categories have a natural order.

You create factor(c("Low", "High", "Moderate")) without setting the levels. In what order are the levels?

By default, R sorts the levels alphabetically. That’s why you should specify levels = ... for ordinal variables.

Lesson summary

  • Categorical variables are stored as factors: factor(x).
  • levels() shows (and renames) the categories; set your own order with factor(x, levels = ...).
  • summary() and table() count observations per category; table(a, b) cross-tabulates.
  • Ordinal variables become ordered factors with ordered = TRUE, and their elements can be compared with < and >.
