R for Sport & Exercise Science

A self-paced, interactive introduction to R for sports science and kinesiology students

Welcome! 👋 This course teaches you R, the programming language used by sport scientists, biomechanists, physiologists and performance analysts to clean, analyse and visualise data.

You don’t need to install anything to get started. Every page has live R code that runs directly in your web browser. Read a concept, try it immediately, check your answer, and test yourself with a quiz.

The data you will use

Modules 2–4 use real force-platform data: the raw force curves of three countermovement jumps by a professional basketball player, CMJ variables of 84 professional basketball and soccer players, and three repeated jumps of 56 players for reliability analysis.

Module 1 mainly uses a real, open dataset of balance assessments: 163 adults (18–86 years) who completed the Mini-BESTest, questionnaires on fear of falling and physical activity, and cognitive tests (Santos & Duarte, 2016, PeerJ). You can read more about it in How this course works.
