1.6 Module checkpoint

Put everything from Module 1 together

NoteHow this checkpoint works

This page mixes quiz questions and mini-projects covering all of Module 1. Try to answer without looking back at the lessons. If you get stuck, go back to the relevant lesson (linked in each section). When you are done, mark the module as complete at the bottom.

⏱️ About 30 minutes.

Part A · Quick quiz

What does this code print?

sets <- 4
reps <- 8
sets * reps

sets holds 4 and reps holds 8, so sets * reps is 32. See lesson 1.1.

What is class(c(1.5, 2, 3))?

A vector’s class is the type of its elements. All three are (decimal) numbers, so the class is numeric.

sprints <- c(4.1, 3.9, 4.4, 4.0). Which code returns only the times faster than 4.05 s?

sprints < 4.05 alone gives a logical vector (FALSE TRUE FALSE TRUE). Putting it inside [ ] selects the values: 3.9 4.0. See lesson 1.2.

Training intensity zones are recorded as "Z1", "Z2", "Z3". What is the best way to store them?

Intensity zones are categories with a natural order, i.e. an ordinal variable. See lesson 1.3.

Which code selects the minibest scores of all women in balance?

Inside square brackets you need the full column reference balance$sex. (With subset(balance, sex == "F") you could use the bare name.) See lesson 1.4.

In ggplot(balance, aes(x = age, y = minibest)) + geom_point(colour = "red"), why is colour outside aes()?

Outside aes() = one fixed value for all points. Inside aes() = the colour depends on a variable in the data. See lesson 1.5.

You want to compare the distribution of Mini-BESTest scores between three activity levels, showing every participant. Which plot is best?

A raincloud plot shows each group’s distribution shape, a box plot summary and the raw data points.

Part B · Mini-project: the fallers

A physiotherapist asks you: “Do people who have fallen in the past year have poorer balance, and does that depend on age?” Let’s explore this step by step.

  1. Add a column faller to balance containing "Faller" if falls_12m is 1 or more and "Non-faller" otherwise. (The function ifelse(condition, value_if_true, value_if_false) does this in one line. It’s given for you.)
  2. Count the participants in each combination of faller and age_group with table() and store it in faller_table.
  3. Calculate the mean Mini-BESTest score of the fallers and store it in mean_fallers.
  1. table(balance$faller, balance$age_group)
  2. subset(balance, faller == "Faller"), then mean(fallers$minibest)

Part C · Mini-project: your own figure

Make a scatter plot of age (x) against fes_total (fear-of-falling score, y), with points coloured by sex, a linear trend line per sex (geom_smooth(method = "lm", se = FALSE)), and theme_minimal().

geom_point(), then geom_smooth(method = "lm", se = FALSE), then theme_minimal(), all connected with +.

ggplot(balance, aes(x = age, y = fes_total, colour = sex)) + geom_point() + geom_smooth(method = "lm", se = FALSE) + theme_minimal()
