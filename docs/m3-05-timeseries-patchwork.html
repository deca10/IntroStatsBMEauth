3.5 Force–time curves and multi-panel figures

Aligning and normalising time-series data, and combining plots with patchwork

NoteIn this lesson you will learn to
  • overlay repeated trials by aligning them to an event (take-off),
  • normalise force to body weight,
  • reshape wide data (left and right columns) into long format for plotting,
  • shade phases of a movement,
  • combine several plots into one figure with patchwork.

⏱️ About 45 minutes. This lesson uses Athlete K’s force data from Module 2.

The problem: trials don’t start at the same time

Let’s overlay Athlete K’s three jumps:

The recordings started at different moments before each jump, so the curves are shifted and hard to compare. The solution is to align the trials to a common event. Take-off is easy to detect: it’s the first sample where the force drops below a small threshold (20 N).

Aligning to take-off

First find the take-off time of each trial. tapply() applies a function per group, and the function can be one you write on the spot:

takeoff is a named vector, so takeoff["CMJ 2"] gives the take-off time of CMJ 2, and takeoff[cmj$trial] gives the take-off time of the matching trial for every row. Subtracting it creates a time axis where 0 = take-off:

Plot the aligned trials: time_rel (x) against force_total (y), one coloured line per trial. Zoom in on the interval from −1.2 s to 0.8 s with coord_cartesian(), and add a dashed vertical line at take-off (geom_vline(xintercept = 0, linetype = "dashed")).

x = time_rel, colour = trial, xintercept = 0, xlim = c(-1.2, 0.8).

takeoff <- tapply(cmj$time_s[cmj$force_total < 20], cmj$trial[cmj$force_total < 20], min) cmj$time_rel <- cmj$time_s - takeoff[cmj$trial] ggplot(cmj, aes(x = time_rel, y = force_total, colour = trial)) + geom_line() + geom_vline(xintercept = 0, linetype = "dashed") + coord_cartesian(xlim = c(-1.2, 0.8))

Normalising to body weight

Forces are often expressed in multiples of body weight (BW), which makes athletes of different sizes comparable and makes the curve easier to read: 1 BW = standing still, 0 = flight. Athlete K’s body weight is ≈ 726 N (lesson 2.2):

Wide vs. long data: left and right legs

cmj stores the two legs in two columns (force_left, force_right). That’s called wide format. ggplot2 wants long format instead: one column with the force and one column saying which leg it belongs to. Then you can simply map colour = leg.

You can build the long data by stacking two data frames with rbind():

(The tidyr package’s pivot_longer() does this in one step, which is very useful once you have many columns.)

Build legs for CMJ 1 (as above) and plot the left and right force over time as two coloured lines. Shade the flight phase with annotate("rect", ...): in CMJ 1 the flight lasts from about 4.58 s to 5.16 s. Use ymin = -Inf, ymax = Inf so the shading covers the full height, with alpha = 0.2.

force_left and force_right; colour = leg; xmin = 4.58, xmax = 5.16.

cmj1 <- subset(cmj, trial == "CMJ 1") legs <- rbind( data.frame(time_s = cmj1$time_s, leg = "Left", force = cmj1$force_left), data.frame(time_s = cmj1$time_s, leg = "Right", force = cmj1$force_right) ) ggplot(legs, aes(x = time_s, y = force, colour = leg)) + annotate("rect", xmin = 4.58, xmax = 5.16, ymin = -Inf, ymax = Inf, alpha = 0.2) + geom_line() + labs(x = "Time (s)", y = "Vertical force (N)")

Why do we align repeated trials to take-off before overlaying them?

Time since the start of the recording has no biomechanical meaning. Aligning to a clear event (onset, take-off, foot contact) makes the phases comparable across trials and athletes.

Three separate layers works, but it doesn’t scale and you lose the automatic legend. Long (“tidy”) data, with one row per observation, is what ggplot2 is designed for.

Combining plots with patchwork

Journal figures often have several panels (A, B, C…). The patchwork package lets you combine ggplot objects with simple operators:

Code Layout
p1 + p2 or p1 | p2 side by side
p1 / p2 on top of each other
(p1 | p2) / p3 two on top, one below
+ plot_annotation(tag_levels = "A") add panel tags A, B, C
+ plot_layout(guides = "collect") combine duplicate legends into one

Together, the three panels tell a story: soccer players jump slightly higher (A), but they are also much lighter (C), and lighter athletes tend to jump higher (B). Is it the sport or the body mass? You’ll answer that with multiple regression in Module 4.

Combine the two plots p_force and p_power (given) side by side, with panel tags A and B, and with their two identical legends collected into one.

(p_force | p_power), tag_levels = "A", guides = "collect". The brackets matter: + is evaluated before |, so without them the annotation would be added to p_power only.

p_force <- ggplot(squad, aes(x = con_force_rel, y = jump_height_m, colour = sport)) + geom_point() + scale_colour_manual(values = sport_cols) + labs(x = "Mean propulsive force (N/kg)", y = "Jump height (m)", colour = NULL) p_power <- ggplot(squad, aes(x = peak_power_rel, y = jump_height_m, colour = sport)) + geom_point() + scale_colour_manual(values = sport_cols) + labs(x = "Peak power (W/kg)", y = "Jump height (m)", colour = NULL) (p_force | p_power) + plot_annotation(tag_levels = "A") + plot_layout(guides = "collect")

Lesson summary

  • Align repeated trials to an event: time_rel <- time - event_time[trial], using a named vector of event times from tapply().
  • Normalise force to body weight (force / bw) to compare athletes and read curves easily.
  • ggplot2 prefers long data: stack columns with rbind() (or tidyr::pivot_longer()), then map colour = group.
  • Shade phases with annotate("rect", xmin, xmax, ymin = -Inf, ymax = Inf, alpha = ...).
  • patchwork: | side by side, / stacked, plot_annotation(tag_levels = "A"), plot_layout(guides = "collect").
