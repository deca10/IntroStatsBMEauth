1.5 Plotting with ggplot2

Histograms, scatter plots, box plots, raincloud plots and line plots

NoteIn this lesson you will learn to
  • build plots layer by layer with the grammar of graphics,
  • make histograms, scatter plots, box plots, raincloud plots and line plots,
  • use the aesthetics fill, colour and group, and know when to put them inside or outside aes().

⏱️ About 50 minutes. This page loads the ggplot2 and ggdist packages, which can take up to a minute the first time.

TipData on this page

The balance dataset is loaded for you. The columns activity and fear_falling are already (ordered) factors with the levels Low, Moderate, High, just as you learned in lesson 1.3. A second dataset, hr_test, is introduced in the line-plot section.

The grammar of graphics

ggplot2 is the most popular plotting package in R. It builds every plot from the same three ingredients:

  1. data: a data frame,
  2. aesthetics (aes()): which columns go on which visual property, e.g. x, y, colour, fill,
  3. geoms (geom_...()): the geometric shapes that represent the data, e.g. points, bars, boxes, lines.

You start a plot with ggplot() and add layers with +:

ggplot(data = my_data, aes(x = column1, y = column2)) +
  geom_point()

Before you can use ggplot2 you load it with library(ggplot2). On this page that’s already done for you. Run the code below to see your first plot:

ImportantPut the + at the end of the line

The + must be at the end of a line, not at the start of the next one. Otherwise R thinks the plot is finished and doesn’t know what to do with the next line.

Histograms

A histogram shows the distribution of one numeric variable: the x-axis is divided into intervals (bins) and the height of each bar is the number of observations in that bin. Only an x aesthetic is needed.

The binwidth argument sets the width of each bin (here 2 points). Always try a few values: too wide hides details, too narrow makes the histogram noisy.

fill and colour

Two aesthetics control colour, and beginners often mix them up:

  • fill is the colour inside a shape (the bars),
  • colour (or color) is the colour of the outline (or of points and lines).

Make a histogram of participants’ age with a binwidth of 5 years, dark-green bars (fill = "darkgreen") and black outlines (colour = "black").

aes(x = age) and geom_histogram(binwidth = 5, fill = "darkgreen", colour = "black").

ggplot(balance, aes(x = age)) + geom_histogram(binwidth = 5, fill = "darkgreen", colour = "black") 
ggplot(balance, aes(x = age)) +
  geom_histogram(binwidth = 5, fill = "darkgreen", colour = "black")

Mapping fill to a variable

So far we set fill to one fixed colour. You can also map fill to a column inside aes(). ggplot2 then gives each group its own colour and adds a legend automatically:

alpha (0–1) makes the bars transparent so both groups are visible, and position = "identity" draws them on top of each other instead of stacking them.

TipThe golden rule
  • Inside aes() → the colour depends on the data: aes(fill = age_group)
  • Outside aes() → one fixed value for everything: geom_histogram(fill = "steelblue")

You write geom_histogram(aes(fill = "blue")). What happens?

Inside aes(), ggplot2 treats "blue" as a data value (a group called “blue”), not as a colour, so it picks its own colour and adds a legend. To make the bars blue, put it outside: geom_histogram(fill = "blue").

Which aesthetic changes the colour of the outline of histogram bars?

colour (or color) controls outlines, points and lines. fill controls the inside of shapes. alpha controls transparency.

Scatter plots

A scatter plot shows the relationship between two numeric variables, one point per observation. Use geom_point().

Each point is a participant. There is a clear pattern: older participants tend to have lower Mini-BESTest scores. Note: size and alpha are set outside aes(), so they apply to all points.

For points, colour is the most important aesthetic (points have no inside to fill). Mapping it to a categorical variable shows groups:

You can add a trend line with geom_smooth(). method = "lm" draws a straight (linear regression) line, and se = FALSE hides the confidence band:

Because colour = sex is in the main ggplot() call, both layers use it, so you get one line per sex.

aes(x = tmt_a_s, y = minibest, colour = age_group) and the geom for points is geom_point().

Box plots

A box plot summarises a numeric variable for each group. Put the grouping (categorical) variable on x and the numeric variable on y:

How to read it:

  • the thick line in the box is the median,
  • the box covers the middle 50 % of the data (from the 25th to the 75th percentile, the interquartile range, IQR),
  • the whiskers extend to the most extreme values within 1.5 × IQR of the box,
  • dots beyond the whiskers are potential outliers.

Box plots look better with fill. Map it to the same variable as x to colour each box (show.legend = FALSE hides the then-redundant legend):

Map fill to a different variable to compare subgroups side by side:

Make a box plot of fear-of-falling score (fes_total, y-axis) for each physical-activity level (activity, x-axis), with the boxes filled by activity. Because activity is an ordered factor, the boxes appear in a logical order: Low, Moderate, High.

aes(x = activity, y = fes_total, fill = activity) + geom_boxplot().

ggplot(balance, aes(x = activity, y = fes_total, fill = activity)) + geom_boxplot() 
ggplot(balance, aes(x = activity, y = fes_total, fill = activity)) +
  geom_boxplot()

In a box plot, what does the line inside the box represent?

The line is the median (50th percentile). Box plots don’t show the mean by default.

Raincloud plots

Box plots hide the shape of the distribution and how many observations there are. A raincloud plot combines three layers to show everything at once:

  1. a half-violin (“cloud”): the shape of the distribution,
  2. a narrow box plot: the median and quartiles,
  3. the raw data points (“rain”).

ggplot2 doesn’t have a raincloud geom, but because plots are built from layers, you can stack the three yourself. The half-violin comes from the ggdist package (stat_halfeye()), which is loaded on this page.

What the arguments do:

  • adjust controls the smoothness of the cloud (smaller = more detail),
  • justification moves the cloud away from the box,
  • .width = 0 and point_colour = NA hide the interval and point that stat_halfeye() draws by default,
  • geom_jitter() is geom_point() with a small random horizontal shift,
  • coord_flip() swaps x and y, giving the typical horizontal “raincloud” look.

Now you can see that the old group’s scores are spread out widely, while most young participants score close to the maximum: something a box plot alone doesn’t show.

The raincloud plot below is missing its rain. Complete it so it shows BMI (bmi) for each sex, and add the raw-data layer with geom_jitter(width = 0.05, alpha = 0.4).

Use y = bmi, and replace the second blank with geom_jitter(width = 0.05, alpha = 0.4).

ggplot(balance, aes(x = sex, y = bmi, fill = sex)) + stat_halfeye(adjust = 0.6, width = 0.6, justification = -0.25, .width = 0, point_colour = NA) + geom_boxplot(width = 0.12, outlier.shape = NA) + geom_jitter(width = 0.05, alpha = 0.4) + coord_flip() 
ggplot(balance, aes(x = sex, y = bmi, fill = sex)) +
  stat_halfeye(adjust = 0.6, width = 0.6, justification = -0.25,
               .width = 0, point_colour = NA) +
  geom_boxplot(width = 0.12, outlier.shape = NA) +
  geom_jitter(width = 0.05, alpha = 0.4) +
  coord_flip()

What is the main advantage of a raincloud plot over a box plot?

Box plots summarise data with five numbers. Two very different distributions (e.g. one with two peaks) can produce the same box. Raincloud plots show the shape and every observation as well.

Line plots

Line plots connect observations in order, usually over time. They’re ideal for repeated measurements: heart rate during a test, force during a jump, performance over a season.

To practise, here is a small simulated dataset, hr_test: three athletes completed an incremental treadmill test, and their heart rate (hr, bpm) was recorded every minute.

Why you need group

Let’s try a line plot with just x and y:

That’s a mess! ggplot2 doesn’t know that the data belongs to three different athletes, so it draws one line that zig-zags between them. The group aesthetic tells ggplot2 which observations belong together:

Now there’s one line per athlete, but we can’t tell who is who. Mapping colour to athlete fixes that. Mapping a categorical variable to colour also groups the data automatically. Adding geom_point() marks the actual measurements:

Make a line plot of hr_test with minute on the x-axis and hr on the y-axis. Use group = athlete and colour = athlete, and add both geom_line() and geom_point().

aes(x = minute, y = hr, group = athlete, colour = athlete), then geom_line() + geom_point().

ggplot(hr_test, aes(x = minute, y = hr, group = athlete, colour = athlete)) + geom_line() + geom_point() 
ggplot(hr_test, aes(x = minute, y = hr, group = athlete, colour = athlete)) +
  geom_line() +
  geom_point()

Lines for group means

Line plots are also used to show summary values across ordered categories. The data frame best_by_age (created for you) contains the mean Mini-BESTest score for each age band and sex:

Plot best_by_age with age_band on the x-axis, minibest on the y-axis and one coloured line per sex. Because age_band is categorical, you must set group = sex for the lines to be drawn. Add points too.

Both blanks are sex.

ggplot(best_by_age, aes(x = age_band, y = minibest, group = sex, colour = sex)) + geom_line() + geom_point() 
ggplot(best_by_age, aes(x = age_band, y = minibest, group = sex, colour = sex)) +
  geom_line() +
  geom_point()

Your line plot shows a single zig-zag line instead of one line per participant. What’s the most likely fix?

Lines connect observations within a group. Without a group (or a discrete colour), ggplot2 puts all observations in one group and connects them all.
