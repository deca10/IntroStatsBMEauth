1.1 R basics

Arithmetic, variables and the basic data types

NoteIn this lesson you will learn to
  • use R as a calculator for everyday sport-science calculations,
  • store values in variables,
  • recognise R’s basic data types and check them with class().

⏱️ About 30 minutes.

Why R?

Sport and exercise scientists collect a lot of data: jump heights from force plates, heart rates from chest straps, GPS distances, questionnaire scores, lab test results. Spreadsheets are fine for small tasks, but they become slow and error-prone as data grows. R is a free programming language designed for data analysis and statistics. With R you write down every step of your analysis as code, so it is reproducible: you (or your supervisor) can re-run it at any time and get exactly the same result.

Arithmetic with R

In its most basic form, R is a powerful calculator. These are the arithmetic operators:

Operator Meaning Example Result
+ addition 5 + 3 8
- subtraction 5 - 3 2
* multiplication 5 * 3 15
/ division 6 / 4 1.5
^ exponentiation (power) 2 ^ 3 8
%% modulo (remainder of a division) 7 %% 3 1

R follows the usual order of operations: brackets first, then powers, then multiplication/division, then addition/subtraction. Run the code below, then change it and run it again. This box is your console for experimenting.

Each line produces its own output, shown below the code. Lines starting with # are comments: R ignores them, and you use them to explain your code to humans.

An athlete completes 3 laps of 400 m followed by 4 laps of 200 m. Write a single line of R code that calculates the total distance in metres.

Multiply the number of laps by the lap length for each part, then add the two parts: 3 * ___ + 4 * ___.

# Total distance in metres 3 * 400 + 4 * 200 
# Total distance in metres
3 * 400 + 4 * 200

A 1RM (one-repetition maximum) test gives 140 kg. Your athlete should train at 75 % of their 1RM. Calculate the training load in kg.

75 % is the same as 0.75. Multiply it by 140.

# 75 % of a 140 kg 1RM 140 * 0.75 
# 75 % of a 140 kg 1RM
140 * 0.75

What does R return for 2 + 3 * 2?

Multiplication is done before addition: 3 * 2 = 6, and then 2 + 6 = 8. If you wanted 10 you would need brackets: (2 + 3) * 2.

What is the result of 17 %% 5?

%% gives the remainder of a division. 5 goes into 17 three times (15), with 2 left over.

Variable assignment

A basic concept in programming is the variable. A variable lets you store a value (e.g. 52) or an object (e.g. a whole dataset) under a name, so you can use it later.

In R you assign a value to a variable with the assignment operator <- (a “less than” sign followed by a minus). Read it as “gets”:

vo2max <- 52     # "vo2max gets 52"

After that, typing the variable’s name prints its value:

TipNaming rules

Variable names can contain letters, numbers, _ and ., but must start with a letter. They are case sensitive: vo2max and VO2max are two different variables. Choose names that describe the content, like jump_height or resting_hr.

Create a variable called resting_hr and assign the value 58 (beats per minute) to it. Then print it by typing its name on a new line.

Use resting_hr <- 58 on the first line, and just resting_hr on the next line.

# Assign the value 58 to resting_hr resting_hr <- 58 # Print out the value of resting_hr resting_hr 
# Assign the value 58 to resting_hr
resting_hr <- 58

# Print out the value of resting_hr
resting_hr

Variable assignment (2)

Variables become really useful when you combine them. Suppose an athlete’s best lifts are stored in variables. You can calculate with the names instead of the numbers:

If the athlete improves, you only change the value once and every calculation that uses the variable updates automatically.

A powerlifting total is the sum of the best squat, bench press and deadlift.

  1. Assign 150 to squat_kg, 95 to bench_kg and 180 to deadlift_kg.
  2. Create a variable total_kg that is the sum of the three lifts (use the variable names, not the numbers).
  3. Print total_kg.

The total is squat_kg + bench_kg + deadlift_kg. Print it by writing total_kg on the last line.

# Assign the three lifts squat_kg <- 150 bench_kg <- 95 deadlift_kg <- 180 # Create total_kg using the three variables total_kg <- squat_kg + bench_kg + deadlift_kg # Print total_kg total_kg 
# Assign the three lifts
squat_kg <- 150
bench_kg <- 95
deadlift_kg <- 180

# Create total_kg using the three variables
total_kg <- squat_kg + bench_kg + deadlift_kg

# Print total_kg
total_kg

Variable assignment (3)

What happens if you try to add a number and a piece of text? Run this code and read the error message:

R complains: “non-numeric argument to binary operator”. The quotation marks around "0.15" make it text, not a number, and you can’t do arithmetic with text. Error messages may look scary, but they are R’s way of telling you exactly what went wrong. Reading them carefully is an important skill.

Fix the code so that total_time is calculated correctly. Don’t change the numbers, only the way one of them is written.

Remove the quotation marks around 0.15 so that R treats it as a number.

sprint_time <- 11.2 reaction_time <- 0.15 total_time <- sprint_time + reaction_time total_time 
sprint_time <- 11.2
reaction_time <- 0.15

total_time <- sprint_time + reaction_time
total_time

After running jump <- 35 and then jump <- jump + 5, what is the value of jump?

The right-hand side is calculated first using the old value (35 + 5 = 40), and the result is then stored in jump, overwriting the old value. Overwriting variables is allowed in R.

Basic data types in R

R works with several data types. The four you will meet most often are:

Type What it stores Examples
numeric Decimal numbers 4.5, 72, -0.3
integer Whole numbers (written with an L) 4L, 12L
character Text (also called strings), always in quotes "Maria", "midfielder"
logical TRUE or FALSE (no quotes!) TRUE, FALSE

Note that numbers like 72 are numeric by default; R only makes them integers if you add an L. In practice, you rarely need to worry about that difference.

Create the following variables describing a basketball player:

  • player with the text Nikos,
  • height_m with the number 1.98,
  • starter with the logical value TRUE.

Text needs quotation marks ("Nikos"), numbers don’t (1.98), and logical values are written in capitals without quotes (TRUE).

# Character: the player's name player <- "Nikos" # Numeric: height in metres height_m <- 1.98 # Logical: is he in the starting five? starter <- TRUE 
# Character: the player's name
player <- "Nikos"

# Numeric: height in metres
height_m <- 1.98

# Logical: is he in the starting five?
starter <- TRUE

What’s that data type?

When R gives you an unexpected error, the reason is often that a value has a different type than you thought (like "0.15" earlier). You can ask R for the type of any value or variable with the function class():

Three variables are created for you. Use class() to find the data type of sport (as the last line of your code).

Put the name of the variable inside the brackets: class(sport).

sport <- "rowing" distance_m <- 2000 personal_best <- FALSE # Check the class of sport class(sport) 
sport <- "rowing"
distance_m <- 2000
personal_best <- FALSE

# Check the class of sport
class(sport)

What does class("72") return?

Anything inside quotation marks is text, so "72" is a character value even though it looks like a number.

Which of these values is a logical?

Logical values are written in capitals without quotes: TRUE and FALSE. "FALSE" is text, and false (lower case) is not recognised by R. It would look for a variable called false.

Lesson summary

  • R can be used as a calculator: + - * / ^ %%, with the usual order of operations.
  • Store values with <-: resting_hr <- 58. Variable names are case sensitive.
  • The basic data types are numeric, integer, character (text, in quotes) and logical (TRUE/FALSE).
  • class() tells you the type of a value.
