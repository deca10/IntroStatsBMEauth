1.4 Data frames

Exploring, creating, selecting and sorting a real balance dataset

NoteIn this lesson you will learn to
  • explain what a data frame is,
  • get a quick overview of a dataset with head(), str() and summary(),
  • create your own data frame,
  • select rows and columns, and filter participants with conditions,
  • sort a data frame.

⏱️ About 45 minutes.

What’s a data frame?

So far you have stored one variable at a time in a vector. Real datasets contain many variables measured on the same participants: age, sex, body mass, test scores… These variables have different types (numeric, character, logical), so a single vector can’t hold them.

A data frame is R’s version of a spreadsheet table:

  • each row is one observation (e.g. one participant or one trial),
  • each column is one variable,
  • each column is a vector, so all values in a column have the same type, but different columns can have different types.

In this lesson you’ll work with the balance dataset: 163 adults aged 18–86 who completed a balance assessment (Santos & Duarte, 2016). It has been loaded for you with:

balance <- read.csv("data/balance.csv")

read.csv() reads a comma-separated file, the most common way to bring data into R. See How this course works for a description of all columns.

Quick, have a look at your dataset

Printing a whole dataset fills the screen. Usually you just want a quick look at the first or last rows. The function head() shows the first 6 rows and tail() the last 6:

You can ask for a different number of rows with a second argument: head(balance, n = 3). Other helpful functions are dim() (number of rows and columns), nrow(), ncol() and names() (the column names).

Show the last 4 rows of balance using tail().

tail() works just like head(): tail(balance, n = 4).

# Show the last 4 rows of balance tail(balance, n = 4) 
# Show the last 4 rows of balance
tail(balance, n = 4)

dim(balance) returns 163 18. What does this mean?

dim() always gives rows first, then columns. Each row is one participant, each column a variable.

Have a look at the structure

The function str() (structure) is the best first look at a new dataset. It shows:

  • the number of observations (rows) and variables (columns),
  • each column’s name and type (num, int, chr, logi),
  • the first few values of every column.

summary() goes one step further and gives descriptive statistics for every numeric column (minimum, quartiles, median, mean, maximum, and the number of missing values, NA):

Use summary() on the tmt_b_s column (Trail Making Test B time, in seconds) to find its median. Use the $ sign to select the column: balance$tmt_b_s.

Write summary(balance$tmt_b_s).

# Summarise the tmt_b_s column summary(balance$tmt_b_s) 
# Summarise the tmt_b_s column
summary(balance$tmt_b_s)

In the output of str(balance), the column sex is shown as chr. What does that tell you?

chr stands for character. Since R 4.0, read.csv() keeps text columns as character by default. Convert them with factor() when you need categories (for example for statistics or plots).

Creating a data frame

You can also build a data frame yourself from vectors of equal length, with the function data.frame(). Each argument becomes a column: column_name = vector.

Creating a data frame (example)

You tested five sprinters. Create a data frame called sprinters from the vectors below, with the columns in this order: athlete, sex, sprint_30m and injured. Then look at its structure with str().

data.frame(athlete, sex, sprint_30m, injured), then str(sprinters).

athlete <- c("Eleni", "Marco", "Sofia", "Jonas", "Lea") sex <- c("F", "M", "F", "M", "F") sprint_30m <- c(4.31, 3.98, 4.12, 4.05, 4.45) # seconds injured <- c(FALSE, FALSE, TRUE, FALSE, FALSE) # Create the data frame sprinters <- data.frame(athlete, sex, sprint_30m, injured) # Check its structure str(sprinters) 
athlete    <- c("Eleni", "Marco", "Sofia", "Jonas", "Lea")
sex        <- c("F", "M", "F", "M", "F")
sprint_30m <- c(4.31, 3.98, 4.12, 4.05, 4.45)   # seconds
injured    <- c(FALSE, FALSE, TRUE, FALSE, FALSE)

# Create the data frame
sprinters <- data.frame(athlete, sex, sprint_30m, injured)

# Check its structure
str(sprinters)

Selection of data frame elements

Like vectors, you select from data frames with square brackets, but now you give two positions: [rows, columns].

my_df[1, 2]      # row 1, column 2
my_df[1:3, 2:4]  # rows 1-3, columns 2-4
my_df[1, ]       # all columns of row 1 (leave the column part empty)
my_df[, 2]       # all rows of column 2 (leave the row part empty)

Instead of column numbers you can use column names, which makes your code much easier to read:

Select the values of the columns age, sex and minibest for the first 10 participants (rows 1 to 10). Store the result in first10.

Rows: 1:10. Columns: c("age", "sex", "minibest"). Don’t forget the comma between them.

# Rows 1 to 10, columns age, sex and minibest first10 <- balance[1:10, c("age", "sex", "minibest")] first10 
# Rows 1 to 10, columns age, sex and minibest
first10 <- balance[1:10, c("age", "sex", "minibest")]

first10

Selection of data frame elements (2)

To select a whole column you’ll most often use the dollar sign: data$column. This returns the column as a vector, so everything from the vectors lesson works:

Now combine it with selection by comparison. A logical vector in the row position keeps only the rows where it is TRUE:

The function subset() does the same with less typing: you can use the column names directly.

Select all participants with a Mini-BESTest score below 15 (a sign of poor balance). Store them in poor_balance, using either subset() or square brackets. Then print only their age, sex, minibest and falls_12m.

subset(balance, minibest < 15) or balance[balance$minibest < 15, ].

# Participants with minibest below 15 poor_balance <- subset(balance, minibest < 15) # Show age, sex, minibest and falls_12m poor_balance[, c("age", "sex", "minibest", "falls_12m")] 
# Participants with minibest below 15
poor_balance <- subset(balance, minibest < 15)

# Show age, sex, minibest and falls_12m
poor_balance[, c("age", "sex", "minibest", "falls_12m")]

What is the difference between balance$age and balance[1, ]?

$ selects a column by name (a vector of 163 ages). [1, ] selects row 1 with all columns (one participant).

Exercise with datasets (1)

Time to answer some real research-style questions with what you’ve learned. You’ll often combine selection with mean(), nrow() or table().

  1. Create old, a data frame with only the participants whose age_group is "Old".
  2. Calculate their mean Mini-BESTest score and store it in old_mean.
  3. On the last line, calculate the difference between the young and old group means (young_mean - old_mean).

Copy the pattern of the young lines: subset(balance, age_group == "Old") and mean(old$minibest). Finally young_mean - old_mean.

young <- subset(balance, age_group == "Young") young_mean <- mean(young$minibest) # 1. Older participants old <- subset(balance, age_group == "Old") # 2. Their mean Mini-BESTest score old_mean <- mean(old$minibest) # 3. Difference between the groups young_mean - old_mean 
young <- subset(balance, age_group == "Young")
young_mean <- mean(young$minibest)

# 1. Older participants
old <- subset(balance, age_group == "Old")

# 2. Their mean Mini-BESTest score
old_mean <- mean(old$minibest)

# 3. Difference between the groups
young_mean - old_mean

Exercise with datasets (2)

Often you need to create a new column from existing ones. Assign to a new name with $, and R calculates it for every row at once (vectorisation!):

The difference between Trail Making Test part B and part A (B − A) is often used as a measure of executive function.

  1. Create a new column tmt_diff in balance equal to tmt_b_s - tmt_a_s.
  2. Create faller as a new column that is TRUE if the participant had at least one fall in the past 12 months.
  3. On the last line, make a table of faller by age_group with table().
  1. balance$tmt_b_s - balance$tmt_a_s
  2. balance$falls_12m >= 1 (or > 0)
  3. table(balance$faller, balance$age_group)
# 1. TMT difference (B - A) balance$tmt_diff <- balance$tmt_b_s - balance$tmt_a_s # 2. Did the participant fall at least once? balance$faller <- balance$falls_12m >= 1 # 3. Cross-table of faller and age group table(balance$faller, balance$age_group) 
# 1. TMT difference (B - A)
balance$tmt_diff <- balance$tmt_b_s - balance$tmt_a_s

# 2. Did the participant fall at least once?
balance$faller <- balance$falls_12m >= 1

# 3. Cross-table of faller and age group
table(balance$faller, balance$age_group)

Sorting

To sort data you use the function order(). It doesn’t return the sorted values, but the positions of the elements in sorted order:

The smallest value (31) is at position 3, then 38 at position 1, and so on. Putting those positions inside square brackets gives the sorted vector:

(For a single vector, sort(cmj_cm) is a shortcut, but order() is what you need for data frames.)

x <- c(12, 7, 20). What does order(x) return?

order() returns positions: the smallest value (7) is element 2, then 12 (element 1), then 20 (element 3). sort(x) would return the values 7 12 20.

Sorting your data frame

To sort a data frame by one column, use order() on that column in the row position:

Sort balance by Mini-BESTest score from highest to lowest and store the result in ranked. Then show the first 5 rows of the columns subject, age and minibest.

Order by balance$minibest with decreasing = TRUE.

# Sort by minibest, highest first ranked <- balance[order(balance$minibest, decreasing = TRUE), ] # Top 5 participants head(ranked[, c("subject", "age", "minibest")], n = 5) 
# Sort by minibest, highest first
ranked <- balance[order(balance$minibest, decreasing = TRUE), ]

# Top 5 participants
head(ranked[, c("subject", "age", "minibest")], n = 5)

Which code returns the 10 oldest participants?

Sort from oldest to youngest (decreasing = TRUE) and take the first 10 rows. The first option gives the 10 youngest, and the third selects column 10, not 10 rows.

Lesson summary

  • A data frame stores variables (columns) of different types for the same observations (rows).
  • Explore data with head(), tail(), dim(), str() and summary().
  • Create a data frame with data.frame(col1, col2, ...).
  • Select with df[rows, columns] (positions or names), or a single column with df$col.
  • Filter rows with a logical condition (df[df$x > 5, ]) or subset(df, x > 5).
  • Create new columns with df$new <- ....
  • Sort with df[order(df$col), ], and add decreasing = TRUE for largest first.
