4.1 Sampling and confidence intervals

From one sample to a statement about the population, with honest uncertainty

NoteIn this lesson you will learn to
  • explain why a sample mean is an estimate with uncertainty,
  • calculate the standard error and a 95 % confidence interval (CI) of a mean, by hand and with t.test(),
  • interpret a CI correctly,
  • see how sample size and variability change the width of a CI.

⏱️ About 35 minutes. Module 4 builds directly on Module 2, especially lesson 2.4 (central limit theorem).

From descriptive to inferential statistics

In Module 2 you described data. Now we want to generalise. The squad dataset contains 42 professional soccer players. Their mean jump height is a statistic. What we really want to know is the parameter: the mean jump height of all professional soccer players of this level.

If we had tested 42 other soccer players, we would have found a slightly different mean. This sampling variability is why an estimate always needs a measure of its uncertainty.

The standard error

You met the standard error in lesson 2.4: it’s the standard deviation of the sample means you would get if you repeated the study many times. You can estimate it from a single sample:

\[SE = \frac{SD}{\sqrt{n}}\]

Confidence intervals

A 95 % confidence interval gives a range of plausible values for the population mean:

\[\bar{x} \pm t^* \times SE\]

where \(t^*\) is a value from the t-distribution with n − 1 degrees of freedom. The t-distribution looks like the normal distribution but has heavier tails, which accounts for the extra uncertainty of estimating the SD from a small sample. For large samples \(t^*\) is close to the familiar 1.96. You get it with qt():

(0.975 because 2.5 % is cut off in each tail, leaving 95 % in the middle.)

Calculate the 95 % CI of the mean jump height of the soccer players by hand.

  1. Calculate m (mean), se (standard error) and t_star (with qt(), df = n − 1).
  2. Calculate lower and upper.

m <- mean(x), se <- sd(x) / sqrt(n), t_star <- qt(0.975, df = n - 1), lower <- m - t_star * se, upper <- m + t_star * se.

soccer <- subset(squad, sport == "Soccer") x <- soccer$jump_height_m n <- length(x) # 1. Ingredients m <- mean(x) se <- sd(x) / sqrt(n) t_star <- qt(0.975, df = n - 1) # 2. The interval lower <- m - t_star * se upper <- m + t_star * se c(lower, upper) 
soccer <- subset(squad, sport == "Soccer")
x <- soccer$jump_height_m
n <- length(x)

# 1. Ingredients
m <- mean(x)
se <- sd(x) / sqrt(n)
t_star <- qt(0.975, df = n - 1)

# 2. The interval
lower <- m - t_star * se
upper <- m + t_star * se
c(lower, upper)

What does “95 % confidence” mean?

This is subtle and often misunderstood. The population mean is a fixed (unknown) number; it’s the interval that varies from sample to sample. The correct interpretation:

If we repeated the study many times and calculated a 95 % CI each time, about 95 % of those intervals would contain the true population mean.

A simulation makes this concrete. Let’s pretend we know the truth: jump heights in a population are normal with mean 40 cm and SD 5 cm. We draw 50 samples of 15 athletes and compute a CI from each:

rnorm(n, mean, sd) draws random numbers from a normal distribution, and the for loop repeats the code for i = 1, 2, …, 50. Most intervals (grey) contain the true mean of 40 cm; a few (red) miss it. Run the code with another seed to see that it’s about 95 % in the long run.

A study reports “mean jump height 40.6 cm, 95 % CI 39.0 to 42.1 cm”. Which interpretation is correct?

The first statement confuses the CI of the mean with the spread of individual values (that would be roughly mean ± 2 SD). The second is a very common shortcut; strictly, the true mean is either in the interval or not. The probability belongs to the method, not to one interval.

What makes a CI narrow?

The width of a CI is \(2 \times t^* \times SD / \sqrt{n}\), so a CI gets narrower when:

  • the sample size n increases (but slowly: 4× the athletes for half the width),
  • the variability (SD) is smaller, e.g. thanks to a more reliable test,
  • you accept less confidence (a 90 % CI is narrower than a 95 % CI).

Compare the precision of the estimates for the two sports. Use t.test() to get the 95 % CI of the mean body mass of the basketball players (ci_basket) and of the soccer players (ci_soccer). Then calculate the width of each CI (upper − lower, use diff()).

t.test(basket$body_mass_kg)$conf.int and the same for soccer.

basket <- subset(squad, sport == "Basketball") soccer <- subset(squad, sport == "Soccer") ci_basket <- t.test(basket$body_mass_kg)$conf.int ci_soccer <- t.test(soccer$body_mass_kg)$conf.int # Widths diff(ci_basket) diff(ci_soccer) 
basket <- subset(squad, sport == "Basketball")
soccer <- subset(squad, sport == "Soccer")

ci_basket <- t.test(basket$body_mass_kg)$conf.int
ci_soccer <- t.test(soccer$body_mass_kg)$conf.int

# Widths
diff(ci_basket)
diff(ci_soccer)

You want to halve the width of a confidence interval. Roughly how many more athletes do you need?

The width is proportional to 1/√n. To halve it, √n must double, so n must be 4 times larger.

In a paper, two groups’ means are plotted with error bars that don’t say what they are. Why is that a problem?

For n = 42, the 95 % CI is about 2 × SE, and SD bars are √42 ≈ 6.5 times larger than SE bars. The caption must say which one is shown.

Lesson summary

  • A sample statistic estimates a population parameter; the SE = SD / √n quantifies its precision.
  • 95 % CI = mean ± t* × SE, with t* = qt(0.975, df = n - 1). Shortcut: t.test(x)$conf.int.
  • Interpretation: 95 % of CIs constructed this way contain the true value.
  • Narrower CIs come from larger samples and less variability.
